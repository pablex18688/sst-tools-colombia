# Contribuir

Gracias por querer mejorar SST Tools Colombia.

## Formas de contribuir

- Reportar errores.
- Proponer mejoras de interfaz.
- Mejorar documentación.
- Agregar pruebas.
- Proponer nuevos módulos SST.
- Revisar accesibilidad y uso móvil.

## Flujo recomendado

1. Crea un issue describiendo el problema o mejora.
2. Haz un fork del repositorio.
3. Crea una rama descriptiva.
4. Haz cambios pequeños y claros.
5. Abre un Pull Request explicando qué cambió y por qué.

## Criterios

- No incluir datos personales reales.
- No afirmar cumplimiento legal automático.
- Mantener separados los cálculos técnicos de las interpretaciones normativas.
- Documentar las fuentes cuando se agreguen valores regulatorios.
