# SST Tools Colombia

Herramientas abiertas y gratuitas para apoyar tareas operativas de Seguridad y Salud en el Trabajo (SST) en Colombia y Latinoamérica.

## Primer módulo: Luxometría SST

Esta primera versión permite:

- Registrar mediciones de iluminancia en lux.
- Identificar área, puesto y tipo de fuente de luz.
- Calcular promedio, mínimo, máximo y una uniformidad básica (mínimo/promedio).
- Comparar cada punto contra un valor de referencia definido por el profesional.
- Exportar los datos a CSV.
- Trabajar completamente en el navegador, sin enviar datos a un servidor.

> **Importante:** esta herramienta no sustituye el criterio profesional, la calibración del instrumento, la licencia SST ni los requisitos legales aplicables. Los valores de referencia deben ser definidos por el profesional responsable según la norma o criterio técnico aplicable.

## Objetivo

Facilitar herramientas sencillas a pequeñas empresas, consultores y profesionales SST que hoy realizan muchos registros manualmente en hojas de cálculo o formatos impresos.

## Cómo probarlo

Descarga el proyecto y abre `index.html` en un navegador moderno.
